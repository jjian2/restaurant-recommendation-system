# 🍽️ 맛집 추천 서비스

## 📌 프로젝트 정보
- 기간 : 2024.11 ~ 2025.03  
- 참여 형태 : 개인 프로젝트  
- 기여도 : 100%

## 📖 프로젝트 소개
사용자가 입력한 지역 또는 식당명을 기반으로 블로그 리뷰 데이터를 자동 수집하고,  
감정 분석 결과를 활용하여 맛집을 추천하는 웹 서비스입니다.  

지도 시각화를 통해 식당 위치와 추천 결과를 직관적으로 확인할 수 있도록 구성하였습니다.

## 🧑‍💻 담당 역할
- 서비스 기획 및 전체 시스템 구조 설계  
- 리뷰 수집 및 감정 분석 API 연동  
- 지도 기반 UI 구현 (위치 검색 및 마커 표시)  
- 로그인 및 관리자 기능 개발  
- 데이터 처리 파이프라인 구축  

## 📚 Lesson Learned
- 다중 API 연동 구조 설계 실무 경험  
- 크롤링 및 데이터 전처리 파이프라인 구축  
- Spring Boot와 FastAPI 간 통신 구조 이해  
- 지도 기반 서비스 UX 설계 경험
