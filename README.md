# 🍽️ 맛집 추천 서비스

## 📌 프로젝트 정보
- 기간 : 2024.11 ~ 2025.03  
- 기여도 : 100%

## 📖 프로젝트 소개
사용자가 입력한 지역 또는 식당명을 기반으로 리뷰 데이터를 수집하고 감정 분석을 통해 맛집을 추천하는 웹 서비스입니다.  
지도 시각화를 통해 위치 정보를 직관적으로 제공합니다.

## 🧑‍💻 담당 역할
- 전체 서비스 설계 및 구현  
- 리뷰 수집 및 감정 분석 API 연동  
- 지도 기반 UI 구현  
- 로그인 및 관리자 기능 개발  

## 📚 Lesson Learned
- API 연동 구조 설계 경험  
- 크롤링 및 데이터 처리 파이프라인 구축  
- Spring Boot와 FastAPI 통합 경험
